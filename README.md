- **compliance-rules-engine** — Queryable regulatory knowledge base across 10+ jurisdictions that powers the agent.
- **legal-pdf-extractor** — Deterministic document-AI pipeline for court filings: zone detection, per-field confidence, cross-validation, pytest suite.
- **compliance-exception-tracker · vendor-risk-dashboard · vendor-onboard-stepper** — Compliance ops toolkit for third-party risk teams. Next.js / TypeScript, deployed on Vercel.
- **erp-connector-prototype** — Multi-system data-sync connector. Live on Vercel.
